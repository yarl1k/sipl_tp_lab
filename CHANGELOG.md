# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project follows Semantic Versioning.

## [0.1.0] - 2026-11-17

### Added

- SIPL EBNF specification and dependency-free lexer/parser.
- Typed AST and source spans.
- Interpreter for assignments, sequences, conditionals, loops, blocks and `skip`.
- Execution events and JSON trace output.
- CLI commands: `parse`, `check`, `run`, and `trace`.
- Parse Tree and AST output as text, JSON, DOT, and SVG.
- Conformance fixtures, unit tests, CI and release workflows.
- Python package configuration for PyPI publication.
